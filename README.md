# CompareForge.online

A product comparison and research platform providing structured, evidence-based comparisons.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Project Structure

```
src/
├── app/              # Pages and routes
├── components/       # Reusable components
├── data/             # Comparison and guide data
└── lib/              # Utilities
docs/                 # Project documentation
```

## Documentation

All planning documentation is in the `docs/` directory.
